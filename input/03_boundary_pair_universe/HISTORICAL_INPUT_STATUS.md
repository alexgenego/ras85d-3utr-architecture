# Historical Boundary Pair Universe input status

The two normalized historical input files used for the manuscript-era Boundary Pair Universe (BPU) run are no longer available in the working archive and are therefore not reconstructed or substituted in this public repository.

Recorded historical filenames and SHA-256 checksums:

- `normalized_architecture.csv` — `1a43c903625a90ff0282761acd2665762c41b5cf4ea8ee16d5fd31acdacbb750`
- `interface_catalogue.csv` — `e7d17ce660319099cdc2ef4bbf93695a80dbce72a1a86e7d169fc9c4df364458`

The final BPU builder and conditional permutation scripts are preserved unchanged under `scripts/03_boundary_pair_universe/`. Preserved QC/evidence summaries from the original run are archived under `qc/` and final compact result summaries under `output/`.

The later 510-object D. melanogaster registry is not used as a replacement for the historical 525-object BPU input because the two registries represent different analysis-stage object universes.
