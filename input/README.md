Input data

This directory contains the final analysis input files required to reproduce the custom computational analyses reported in the manuscript.

The input set includes manuscript-relevant tables and coordinate registries used for:

insertion/deletion and IEL analyses;
ECM coordinate mapping;
APA and miRNA annotation;
RNA secondary-structure annotation;
boundary-neighborhood analysis;
Coverage Enrichment and Functional Distance;
Pairwise Architecture Test (PAT);
Architecture Evidence Matrix (AEM) and Basal Architecture Network (BAN);
between-context dispersion analysis.

Only the final validated input versions corresponding to the reported results are included.

Raw public-domain source data are not duplicated here when they remain available from their original repositories. Sequence provenance, accession numbers, genome assemblies, and source coordinates are documented in the manuscript and Supplementary Materials.
