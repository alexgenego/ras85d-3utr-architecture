# Feature catalogue and final registry inputs

This directory contains the preserved final object registry and compact catalogue tables used by the catalogue/registry QC scripts and by downstream PAT/AEM, Coverage Enrichment and Functional Distance analyses.

`29A_3_01_final_object_registry.csv` is the final harmonized three-species registry used to derive the manuscript-associated analytical subsets. Raw external database/web outputs are not treated as experimentally validated functional evidence; their provenance is documented in the manuscript and Supplementary Materials.
