# PAT, AEM, Coverage Enrichment and Functional Distance

Final manuscript-associated implementations and wrappers for the Pairwise Architecture Test (PAT), Architecture Evidence Matrix (AEM), Coverage Enrichment Test, and Functional Distance Test.

Historical filenames containing `authoritative` are retained for provenance and executable compatibility; this term is not used as scientific terminology in the manuscript.

Some original PAT/AEM component scripts contain historical Google Colab paths. The wrapper script is retained together with the final analysis inputs and validation outputs so that the manuscript-associated results can be reproduced and checked without altering the statistical logic.
