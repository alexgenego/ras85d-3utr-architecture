Scripts

This directory contains the final custom scripts used for the manuscript-associated analyses.

Only manuscript-relevant, validated versions are included. Exploratory, intermediate, obsolete, and legacy scripts are excluded from the public reproducibility archive.

Subdirectories will be organized by analytical module, including:

phylogenetic and indel analyses;
boundary-neighborhood analysis;
Coverage Enrichment and Functional Distance;
Pairwise Architecture Test (PAT);
Architecture Evidence Matrix (AEM) and Basal Architecture Network (BAN);
between-context dispersion analysis.
