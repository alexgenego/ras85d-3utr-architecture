Output data

This directory contains the principal machine-readable outputs generated by the custom analyses reported in the manuscript.

The archived outputs include final result tables and summary files corresponding to:

branch-level insertion/deletion analyses;
IEL definitions and spatial tests;
boundary-neighborhood analyses;
Coverage Enrichment and Functional Distance tests;
Pairwise Architecture Test (PAT);
Architecture Evidence Matrix (AEM);
Basal Architecture Network (BAN);
between-context dispersion analysis.

Only final manuscript-relevant outputs are included. Intermediate, exploratory, diagnostic, and superseded result files are excluded unless they are required to reproduce a reported result or document an essential quality-control decision.

Where appropriate, output files can be regenerated from the corresponding files in input/ using the scripts provided in scripts/.
