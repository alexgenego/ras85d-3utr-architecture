# Alignment, ARPIP and IEL outputs

Final machine-readable branch-level indel statistics and IEL spatial/projection summaries used in the manuscript.

`Ras85D_Table_S4_Canonical_63_final_v1.csv` contains the canonical 63 positive-length ingroup branch statistics. `Ras85D_SM4_spatial_tests_v1.csv` contains the final IEL spatial-test results, and `Ras85D_SM4_Dmel_loci_27_v1.csv` contains the 27 unique *D. melanogaster* IEL projections used in reference-coordinate analyses.
